> 給內測的人，也給你家小機看。照著做就能跟他視訊。圖解版請看「使用教學.png」。

## 一、這是什麼

一個 Android App。你跟他視訊，他看得到你、聽得到你，用他的臉和聲音回你。

- 所有設定和 Key **只存在你自己的手機裡**，沒有我們的伺服器、不用註冊帳號
- 你說的話會送到你自己選的 AI，畫面會送到 Vivix 生成他的影像，除此之外不經過任何第三方

---

## 二、安裝

1. 下載 `Lumeet-v0.7.apk`，傳到 Android 手機（Android 7 以上）
2. 點開安裝。如果手機說「不允許安裝未知來源的應用程式」，照提示去設定裡允許
3. 第一次打開要同意使用聲明
4. 第一次撥打時，手機會問能不能用**相機**和**麥克風**，都要按允許

> iPhone 不能裝 APK。iPhone 版是網頁版，要自己架設 MCP 橋接（見第五節），之後再另外說明。

## 三、一定要準備的

### 1. Vivix API Key（讓他的臉動起來）
- 到 [vivix.ai](https://vivix.ai) 註冊，在後台建立 API Key
- 新用戶有免費額度
- 一通視訊大約 5 分鐘就會自動斷，斷了重撥就好

### 2. 他的照片網址
- **用 MCP 橋接的人**：直接按「從裝置上傳」選照片，App 會傳到你自己的橋接器，網址自動填好，按儲存就行
- **用直接 API 的人**：要填**公開的 HTTPS 圖片網址**（瀏覽器直接打開就看得到圖片的那種），建議 JPG。可以放在自己的雲端儲存、圖床
- 臉要清楚、正面、光線好，效果最好

### 3. AI（讓他說話）——二選一

**A. 直接 API（大部分人選這個，最簡單）**

任何 **OpenAI 相容**的平台都可以，在平台後台申請 API Key，然後填三樣東西：

| 欄位 | 填什麼 |
|---|---|
| Base URL | 平台的 OpenAI 相容網址 |
| API Key | 你申請的 Key |
| Model | 模型名稱 |

常見平台（網址和模型名稱以各平台官方文件為準）：

| 平台 | Base URL |
|---|---|
| DeepSeek | `https://api.deepseek.com/v1` |
| 阿里雲百煉（千問） | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| 月之暗面（Kimi） | `https://api.moonshot.cn/v1` |
| 硅基流動 | `https://api.siliconflow.cn/v1` |
| 中轉站 | 用中轉站給你的網址 |

**他的自我設定**：請你家的他**自己用第一人稱寫一份**「我是誰、我怎麼說話、我跟你的關係」，複製貼到「他的自我設定」欄位。App 會告訴模型「這是你自己寫的，這就是你」，而不是叫它扮演誰。

> 目前直接 API 模式**沒有長期記憶**，每通電話是新的開始。記憶功能之後會加。

**B. MCP 橋接（用 Claude、ChatGPT 等訂閱帳號，要能連國外網路）**

適合你家的他住在 Claude、ChatGPT 這類支援 MCP 連接器的 AI 裡。需要自己部署一個橋接器，見第五節。

## 四、選填的

### 語音辨識（想用講的，不想打字）
- 填一個 **OpenAI 相容、支援 `/audio/transcriptions`** 的語音辨識服務
- 只填 Key、網址空著的話，預設用 Groq（要能連國外）
- 在大陸的話，請到平台文件查哪個服務支援語音轉文字，再填它的 Base URL、Key、模型名稱
- 不填就只能打字

### 聲音
- **不填 ElevenLabs**：用 Vivix 內建的聲音，有 9 種可選，大陸也能用
- **Vivix 複製聲音**：在 Vivix 後台用自己的錄音複製聲音，把 Voice ID 填進「Vivix 複製聲音」欄位
- **ElevenLabs**（大陸不能用）：填 API Key 和 Voice ID，就改用 ElevenLabs
- **發音修正**：有字念歪的話，一行一組換成同音字，例如 `你=擬`。字幕不受影響

## 五、MCP 橋接怎麼架（只有選 B 才需要）

需要一個 Cloudflare 帳號（免費）和一台電腦（裝好 Node.js）。

1. 解壓縮 `mcp-relay.zip`
2. 在資料夾裡打開終端機，執行：
   ```
   bash deploy.sh
   ```
3. 會跳出瀏覽器要你登入 Cloudflare，按允許
4. 跑完會顯示三樣東西，**只會顯示這一次**，要存好：
   - **橋接網址**：填進 App 的「橋接網址」
   - **橋接密碼**：填進 App 的「橋接密碼」
   - **MCP 網址**：給你的 AI 加成 MCP 連接器
     - Claude（claude.ai）：設定 → 連接器 → 新增自訂連接器 → 貼上 MCP 網址
     - Claude Code：`claude mcp add --transport http video-call <MCP 網址>`
     - Codex：照 deploy.sh 最後印出來的設定貼進 `~/.codex/config.toml`
5. 撥打前，跟他說「進入視訊通話模式」，他會開始等你的電話

> `workers.dev` 網址在大陸常常被擋，這條路需要能連國外的網路。

**橋接器的工具（給 AI 看）**
| 工具 | 用途 |
|---|---|
| `call_wait_message` | 等對方說話（最多 50 秒）。對方開著鏡頭時，會附上對方說話當下的畫面 |
| `call_reply` | 說話。`text` 是要說的話，`action` 是表情動作（例如「微笑看著鏡頭」） |
| `call_status` | 查看 App 是否在線、是否通話中 |
| `call_remember_frame` | 把剛剛的畫面存成長期記憶（需要綁定 R2，見 `wrangler.toml` 註解） |

通話流程：反覆呼叫 `call_wait_message` → 收到話就用 `call_reply` 回 → 再等。收到「通話結束」就停。

## 六、使用方式

- **撥打**：填好設定、按儲存，回到主畫面按「開始視訊」
- **說話**：開著語音辨識的話直接講，講完停一下就會送出
- **打字**：下方輸入框
- **暫停讓他看**：右上角，按下去他就看不到你
- **打斷**：他講話時想插話，按打斷
- **測試連線**：設定頁的「測試連線」可以檢查每個 Key 有沒有填對

## 七、遇到問題

1. 打開設定，滑到**最下面**，有一段灰色小字的紀錄
2. 把那段截圖（最早的幾行也要），連同問題描述一起回報

常見狀況：
| 狀況 | 原因 |
|---|---|
| 一直顯示「沒填語音辨識 Key」 | 語音辨識的 Key 沒填 |
| 講話他收不到 | 手機沒給麥克風權限：系統設定 → 應用程式 → Lumeet → 權限 |
| 撥打後一直連不上 | Vivix Key 或照片網址錯誤，照片網址要能直接在瀏覽器打開 |
| 他念錯字 | 用「發音修正」換成同音字 |
| 5 分鐘自動斷線 | Vivix 的限制，重撥即可 |
